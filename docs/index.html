Workflow

从页面到表格，三步完成。

不需要打开开发者工具，也不需要复制粘贴。RevHarvest 在你正在浏览的页面内工作。

01
↗

打开评论页

进入受支持的 SHEIN 商品页或独立评论页，确保评论正常可见。

02
↓

开始采集

点击扩展。它会滚动页面、等待懒加载、跨批次去重并显示实时数量。

03
⌁

导出数据

检测到 “No more reviews” 后确认完成，并下载 UTF-8 CSV 或 JSON。

Built for real review pages

面对长列表，仍然
保持可控。

针对动态渲染、懒加载与页面结构变化设计。每一批结果都会保存，意外中断也不必从零开始。

.CSV.JSONUTF-8
01

智能终止判断

识别页面底部的完成标记，在确实加载完成时给出明确状态。

02

稳定去重

优先使用评论 ID；缺少 ID 时，通过规范化内容指纹避免重复记录。

03

进度与恢复

展示采集数量、阶段与错误；支持取消，并保留已经获取的结果。

04

安全导出

CSV 自动处理引号、换行和表格公式注入，JSON 保留完整元数据。

Install locally

两分钟安装到 Chrome。

当前版本通过 Chrome 开发者模式加载。代码完全公开，可在安装前自行检查。

  1. 1

    下载项目从 GitHub 下载 ZIP，并解压到本地文件夹。

  2. 2

    打开扩展程序访问 chrome://extensions 并开启“开发者模式”。

  3. 3

    加载已解压扩展选择项目根目录，然后固定 RevHarvest 图标。
